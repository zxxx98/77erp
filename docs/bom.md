# 单层用料清单与备料测算

桌面、移动 Web 和 PWA 从「生产 → 用料清单」进入，需要独立的「用料清单」权限。物料详情提供「查看用料清单」，按该成品筛选。管理员默认可用，员工由管理员授权。

## 配置与使用

1. 新建用料清单，选择当前仓库已启用的成品，填写清单名称、基准产量和备注。基准产量默认 1，也可按 10、100 等整批产量录入。
2. 搜索材料名称、编码或规格，或扫描已有物料条码 / 二维码添加材料；填写材料用量和备注。单位使用物料档案中的单位。
3. 保存后点击「测算备料」，输入生产数量，查看材料需求、读取时的账面库存和缺料数量，可导出同一份库存快照的 CSV 备料表。

成品和材料均引用现有物料档案，不新增物料类型。每个成品在当前仓库保留一份清单，最多 100 种材料，支持编辑、启停和复制。复制会打开未保存的新清单，保留材料组合并清空成品，需要选择另一成品后保存。

同一材料通过页面再次添加时合并用量；服务端拒绝重复行。成品不能作为自身材料。半成品按一项材料参与计算，即使有自己的 BOM 也不递归展开。计算限定当前仓库，缺料可通过已有采购或仓库调拨补齐。

保存或测算不改变库存、库存价值、采购销售单据及品质验收记录。BOM 本版不记录实际领料或完工入库，不保留库存预留或生产任务。

## 数量和单位

`本次材料需求 = 材料基准用量 × 生产数量 ÷ 基准产量`

数量沿用现有正数、最多 6 位小数及 99999999 上限。使用整数百万分之一和 BigInt 进行乘除，需求仅在最终计算时向上进位至 6 位小数，避免浮点误差和少备料；缺料为 `max(需求 − 账面库存, 0)`。不按“个”“颗”等单位名称推断整件取整规则。

BOM 保存配置时的成品及材料单位。档案单位变化后，已有配方仍可查看；测算会要求先编辑、核对基准产量或用量并重新保存。停用清单、成品或任一材料时不能测算。已引用物料不能直接删除，可保留档案并停用。删除零库存仓库和重置业务数据时同步清理其 BOM。

## 并发、权限及备份

保存和启停检查清单版本，冲突返回 409 并保留页面填写内容。写入使用现有按用户隔离的请求标识避免重复提交。版本序列持久保存，重置或恢复后旧编辑页面不能覆盖新数据。离开未保存页面时沿用全站离开确认。

所有 BOM API 需要登录及 `bom` 权限，资源按当前仓库隔离，不返回财务成本。该权限同时覆盖维护、测算和导出，不授予物料编辑、库存调整或采购销售权限。数据变动接入现有更新提示。

业务备份格式 23 包含 `boms` 和 `bom_items`。恢复校验成品、材料、仓库、单位字段、数量及唯一关系；格式 1–22 恢复为空清单。BOM 变更会使旧恢复预览失效，恢复时重新分配编辑版本。R2 数据库备份自然包含新表。

## AI 助手

同时需要「AI 助手」和「用料清单」权限。`search_boms` 查找当前仓库清单，`get_bom` 读取实际配方，`calculate_bom` 使用明确的生产数量进行同一规则的备料测算。查询不生成写入卡片，不创建或修改 BOM，也不执行领料。关闭 AI 写操作后仍可使用这些查询。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/boms?q=&status=&product_id=&offset=&limit=` | 分页查找当前仓库清单，状态为 all / enabled / disabled |
| GET | `/api/boms/:id` | 查看清单、成品和材料档案 |
| POST | `/api/boms` | 新建，包含 request_id |
| POST | `/api/boms/:id` | 编辑，包含 request_id 和 version |
| POST | `/api/boms/:id/status` | 启停，包含 request_id、version 和 enabled（0 / 1） |
| POST | `/api/boms/:id/calculate` | 只读测算，包含 production_quantity，可附 version 校验当前清单 |

配置包含 `name`、`product_id`、`base_quantity`、`base_unit`、`note`、`enabled`，以及 `items: [{product_id, quantity, unit, note}]`。服务端验证物料属于当前仓库且已启用，并复核单位。测算返回清单版本、生产数量、当前仓库、库存读取时间及逐项材料需求 / 库存 / 缺料，不保存测算记录。

CSV 使用带 BOM 的 UTF-8，记录名称、成品、仓库、基准产量、生产数量、库存读取时间及材料明细；文本字段防止公式执行，数值按快照导出。修改生产数量会清空上次结果，需要重新测算。
