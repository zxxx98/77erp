# 单层 BOM 与备料测算

桌面、移动 Web 和 PWA 从「生产 → BOM」进入，需要独立的「BOM」权限。物料详情提供「查看BOM」，按该成品筛选。管理员默认可用，员工由管理员授权。

## 配置与使用

1. 新建BOM，选择当前仓库已启用的成品，填写 BOM 名称、基准产量和备注。基准产量默认 1，也可按 10、100 等整批产量录入。
2. 搜索材料名称、编码或规格，或扫描已有物料条码 / 二维码添加材料；为整张 BOM 选择「标准损耗计算方式」（内扣法或外包法），填写各材料净用量、标准损耗率和备注。用量可填小数（如 `0.025`）或分数（如 `1/40`），单位使用物料档案中的单位。编辑、复制时保留原分数。
3. 保存后点击「测算备料」，输入生产数量，查看材料需求、读取时的账面库存和缺料数量，可导出同一份库存快照的 CSV 备料表。

成品和材料均引用现有物料档案，不新增物料类型。每个成品在当前仓库保留一份清单，最多 100 种材料，支持编辑、启停和复制。复制会打开未保存的新清单，保留材料组合、损耗率与计算方式并清空成品，需要选择另一成品后保存。

同一材料通过页面再次添加时合并用量；服务端拒绝重复行。成品不能作为自身材料。半成品按一项材料参与计算，即使有自己的 BOM 也不递归展开。计算限定当前仓库，缺料可通过已有采购或仓库调拨补齐。

保存或测算不改变库存、库存价值、采购销售单据及品质验收记录。实际耗料和成品入库通过独立的[生产单](production.md)记录，需要「生产单」权限；可从清单列表新建，或把测算数量带入生产草稿。BOM 测算本身不预留库存、不扣料、不创建任务。

## 数量和单位

计算方式在每张 BOM 的「材料用量」区域选择，适用于全部材料：

- 内扣法（`loss_method=internal`）：`本次材料需求 = 材料基准净用量 × 生产数量 ÷ 基准产量 ÷（1 − 标准损耗率 / 100）`，损耗率按投入量计算。
- 外包法（`loss_method=external`）：`本次材料需求 = 材料基准净用量 × 生产数量 ÷ 基准产量 ×（1 ＋ 标准损耗率 / 100）`，损耗率按净用量计算。

标准损耗率配置在每条 BOM 材料明细，单位为百分数，`10` 表示 10%，可填 0（含）至 100（不含），最多 6 位小数。同一材料在不同 BOM 可以使用不同损耗率；默认 0%，原有用量和历史单据保持原结果。已有 BOM 默认内扣法，计算结果保持原样。净用量 90、损耗率 10%，内扣法标准投入为 100，外包法为 99；净用量 100、损耗率 5%，内扣法为 105.263158，外包法为 105。生产单保存建单时的计算方式，后续更改 BOM 不影响已有生产单。已有用量若已包含损耗，应先核对净用量，避免再加一次。损耗率仅用于标准与计划，不直接扣库或生成废料。

小数用量沿用现有正数、最多 6 位小数及 99999999 上限。分数的分子、分母均为 1–99999999 的整数，不支持零分母、负数、带分数或其他算式。使用 BigInt 保留原分数和损耗率合并进行乘除，需求仅在最终计算时向上进位至 6 位小数；例如 `1/3 × 3 = 1`，不会提前把 `1/3` 转为小数再计算。缺料为 `max(需求 − 账面库存, 0)`。

例如每个纸箱装 40 条电线，可以填写基准产量 1 条、纸箱用量 `1/40` 个，生产 40 条需 1 个纸箱、80 条需 2 个。也可继续填写基准产量 40 条、纸箱用量 1 个。分数表示标准分摊量，不按“个”“箱”等单位名称推断整件取整；生产 41 条的标准用量为 1.025 个，若实际用了 2 个纸箱，在生产完工时把实际耗料改为 2。

BOM 保存配置时的成品及材料单位。档案单位变化后，已有配方仍可查看；测算会要求先编辑、核对基准产量或用量并重新保存。停用清单、成品或任一材料时不能测算。已引用物料不能直接删除，可保留档案并停用。删除零库存仓库和重置业务数据时同步清理其 BOM。

## 并发、权限及备份

保存和启停检查清单版本，冲突返回 409 并保留页面填写内容。写入使用现有按用户隔离的请求标识避免重复提交。版本序列持久保存，重置或恢复后旧编辑页面不能覆盖新数据。离开未保存页面时沿用全站离开确认。

所有 BOM API 需要登录及 `bom` 权限，资源按当前仓库隔离，不返回财务成本。该权限同时覆盖维护、测算和导出，不授予物料编辑、库存调整或采购销售权限。数据变动接入现有更新提示。

业务备份格式 31 增加 BOM 和生产单的 `loss_method`，格式 1–30 恢复为内扣法。格式 25 在格式 23 的 `boms`、`bom_items` 基础上增加材料原分数。恢复校验成品、材料、仓库、单位字段、数量与分数一致性及唯一关系；格式 1–24 的用量按原小数恢复，格式 1–22 恢复为空清单。BOM 变更会使旧恢复预览失效，恢复时重新分配编辑版本。R2 数据库备份自然包含分数。

## AI 助手

同时需要「AI 助手」和「BOM」权限。`search_boms` 查找当前仓库清单，`get_bom` 读取实际配方，`calculate_bom` 使用明确的生产数量进行同一规则的备料测算。查询不生成写入卡片，不创建或修改 BOM，也不执行领料。关闭 AI 写操作后仍可使用这些查询。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/boms?q=&status=&product_id=&offset=&limit=` | 分页查找当前仓库清单，状态为 all / enabled / disabled |
| GET | `/api/boms/:id` | 查看清单、成品和材料档案 |
| POST | `/api/boms` | 新建，包含 request_id |
| POST | `/api/boms/:id` | 编辑，包含 request_id 和 version |
| POST | `/api/boms/:id/status` | 启停，包含 request_id、version 和 enabled（0 / 1） |
| POST | `/api/boms/:id/calculate` | 只读测算，包含 production_quantity，可附 version 校验当前清单 |

配置包含 `name`、`product_id`、`base_quantity`、`base_unit`、`loss_method`、`note`、`enabled`，以及 `items: [{product_id, quantity, quantity_fraction, loss_rate, unit, note}]`。`quantity_fraction` 可省略或为空，表示普通小数；非空时为规范的正整数分数（如 `1/40`），`quantity` 必须等于该分数向上保留 6 位小数的数值，供既有客户端读取。共享函数 `parseBomQuantity` 可生成这两个字段。`loss_method` 为整张 BOM 的损耗计算方式，只允许 `internal`（内扣法）或 `external`（外包法）；新建省略默认为内扣法，旧客户端编辑时省略则保留原方式。`loss_rate` 为标准损耗百分数；新增时省略为 0，编辑旧客户端省略时保留同材料已有损耗率，显式传 0 才清零。服务端校验一致性，按原分数和损耗率测算，并验证物料属于当前仓库且已启用、单位未变化。测算明细同样返回原分数，不保存测算记录。

CSV 使用带 BOM 的 UTF-8，记录名称、成品、仓库、基准产量、生产数量、库存读取时间、损耗计算方式及材料明细；文本字段防止公式执行，数值按快照导出。分数基准用量导出为 `1/40（约 0.025）`，保留比例并避免电子表格将其识别为日期。修改生产数量会清空上次结果，需要重新测算。

## 废料产出

「废料产出」是可选配置，直接选择当前仓库的现有物料，不新增废料档案或物料类型。同一废料可以被不同 BOM 引用，各 BOM 独立配置计算规则。每张 BOM 最多 100 种废料，废料不能重复、不能与成品或投入材料相同；可继续作为原料使用的剩余数量属于余料，实际耗料填净消耗量。

- `output` 按产量计算：`预计废料 = 基准废料量 × 生产数量 ÷ BOM 基准产量`。支持小数和原分数，沿用材料数量的最终向上保留 6 位小数规则。
- `input_ratio` 按指定材料投入计算：`预计废料 = 来源材料投入 × quantity ÷ 100`。`quantity=3` 表示 3%，最多 6 位小数，必须大于 0 且不超过 100；同一来源材料的比例合计不能超过 100%。来源必须是本 BOM 的投入材料，废料与来源单位必须一致，不自动做 kg/g、件/kg 等换算。测算时先计算包含标准损耗的计划投入，再据此计算废料；完工时使用实际耗料，不再乘损耗系数。废料不得再次加到标准投入或从实际耗料中扣除。

规则字段为 `scraps: [{product_id, method, source_product_id, quantity, quantity_fraction, unit, note}]`。按产量的 `source_product_id` 固定为 `null`；比例方式必须指定材料 ID，不接受分数百分比。保存时省略 `scraps` 会保留已有规则，显式传 `[]` 才清空，兼容旧客户端编辑。

测算返回 `scraps`，含物料资料、规则和 `planned_quantity`。页面和 CSV 同时展示预计废料及比例来源；测算仍不改变库存。复制 BOM 会保留废料规则。废料物料停用或单位改变时，需要先核对才能继续测算或建单。仅被废料规则引用的物料也不能删除。

业务备份格式 26 增加 `bom_scraps`，校验来源、单位、比例、排序和仓库关联。格式 1–25 恢复为空废料规则，原有 BOM 数据按对应版本规则恢复。

业务备份格式 28 增加 `bom_items.loss_rate` 和生产材料的损耗率快照，保留并校验比例。格式 1–27 恢复时自动补为 0，不根据废料比例推测历史损耗率。CSV 同时导出基准净用量、标准损耗百分数及含损耗需求。
