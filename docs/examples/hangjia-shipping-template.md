# 航嘉出货报告导入配置

此配置对应用户提供的「出货报告 航嘉 14awg公母插-（汇总）.xlsx」，配置文件为同目录的 `hangjia-shipping-template.json`。仅定义读取规则，不包含正式验收单或物料数据，不自动写入线上仓库。

## 使用

1. 桌面「品质管理 → 模板配置」上传这份原 Excel。
2. 点击「导入字段配置」，选择 `hangjia-shipping-template.json`。
3. 点击「查看完整解析预览」，核对 24 个字段、21 条明细；修改所需规则后保存并启用模板。保存原文件需要已配置 R2。
4. 进入「验收单」，选择此模板，上传填写后的报告，核对所选工作表、物料绑定和解析值，再确认保存。

一个模板仍只配置一个工作表；导入时可选择多个同版式的数据工作表，各自解析和绑定物料。若原 Excel 版式、表头或合并结构变化，应调整模板并重新发布，不能仅靠文件名称套用。

## 配置与边界

- E5:I5 第 1 行为客户料号，配置唯一 KEY；第 2 行为产品名称。唯一 KEY 仅匹配当前仓库已启用物料的编码、名称或客户料号。没有匹配时可手选或取消绑定。
- 批量与抽样量为带 PCS 单位的数字，日期读取 Excel 日期值。
- 检验依据、最终判定采用第 1 行、文字后的 ■/□ 标记。对象内勾选项目根据「检验项目」属性的第 1 行精确匹配规则；未匹配时保持字符串。
- A9:O10 为多级表头，A11:O31 为明细；第 32 行合计单独读取，防止重复统计。
- 检验要求保留完整原文，包括双语和开头空行，不统一截取第 1 行，避免丢失端子外露长要求。
- 明细 CR/MA/MI 中完整文字 `/` 映射为「不适用」，数据值为 null，原文与状态分别保留。该映射只针对缺陷数量字段，不代表整个检验项目已确认不适用。空白仍为空，数字 0 仍为 0。
- 未勾选的 OK/NG 保持未填写，不推断合格或不适用；需要强制检查的项目可以在对应项目规则中勾选「必填」。最终判定为必填。
- 36/56/75、2065/2061/2060、实测值 8.71/8.69 等保持完整文字，不拆分数值或自动判定公差。
- 审核人、检验人读取单元格文字，可随每张报告变化；它们不代表系统账号执行过审批。
- 含项目规则的混合类型属性暂不提供给图表选作字段。可继续使用日期、最终判定、缺陷数量等固定类型字段；本阶段不新增合格率计算、AQL 校验、审批流程。
- 手机 Web/PWA 继续沿用现有品质功能范围，不新增品质管理入口。

## 后续编辑

普通字段与对象属性均支持特殊值映射：先取行、删除忽略内容，再按完整文字匹配。可映射为「不适用」或「未填写」；必填检查允许明确的不适用，拒绝未填写。唯一 KEY 不允许特殊值映射。

对象属性默认类型为字符串时，可以展开「按检验项目配置」，选择同对象的另一个字符串/唯一 KEY 属性作为匹配来源，为每个项目配置独立类型和处理规则。匹配来源不能再有项目规则；同一目标属性不能重复配置同一项目。规则使用属性 ID 关联，模板复制时同步更新引用。

新增配置均为可选，历史模板保持原有解析方式。已保存验收单保留原解析结果，之后修改模板不会重算历史记录。
