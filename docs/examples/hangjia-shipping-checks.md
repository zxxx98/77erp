# 航嘉出货报告：自动核对配置

第二阶段配置文件为 [hangjia-shipping-checks.json](hangjia-shipping-checks.json)。第一阶段的 `hangjia-shipping-template.json` 保留原有行为，便于继续使用已有模板。

## 启用

1. 在桌面「品质管理 → 模板配置」打开已有航嘉模板，或上传原 Excel 新建模板。
2. 点击「导入字段配置」，选择 `hangjia-shipping-checks.json`。核对配置会替换当前草稿字段；已有验收单和发布版本保留。
3. 展开「自动核对规则」，核对公差、要求文字与缺陷数空白处理方式。点击「查看完整解析预览」，检查结果，然后发布新版本。
4. 上传填写后的报告。系统独立显示原报告判定与核对结果；发现差异或数据不足时，查看来源位置并人工核对，勾选确认后才可保存。

确认提示不是系统审批或自动放行。保存时记录确认状态，确认人和时间使用验收单提交人及保存时间。解析错误仍须修正原 Excel，不能靠勾选确认绕过。

## 已配置的核对

| 项目 | 读取与限值 |
| --- | --- |
| 尾部开线 H13:J13 | 按 `/` 拆成 L、N、E，分别为 30–40、50–60、70–80 mm，包含边界。必须恰有三个值，不能互换顺序。 |
| 总长 H15:J15 | 同一项目的多次测量，所有值须在 2050–2090 mm 内，包含边界。 |
| 导体电阻 H23:J23 | 删除“实测值”后按 `/` 拆分，每个值须严格小于 8.88 mΩ/m，等于 8.88 不通过。 |
| 扎线规格 H30:J30 | 中间扎线尺寸多次测量，150–170 mm，包含边界。 |
| CR / MA / MI 合计 | 分别累加明细缺陷数，与第 32 行合计及第 6 行对应不良数比较。明确配置空白按 0 计入，`/` 不适用排除；显式映射为“未填写”、负数和小数均提示人工核对。 |
| 允收／拒收 | 从 M5/N5/O5 读取 Ac/Re，与 M6/N6/O6 比较。原报告为 0/1、3/4、7/8；不依据 AQL 推算抽样计划。 |
| 最终判定 | 比较单项实测/勾选结果与 O 列判定，再结合公差和允收核对，与 I8 原报告判定比较。缺失结果不自动视为合格。 |

公差配置依据这份原报告的要求文字填写，每项同时绑定对应“检验要求”属性。上传文件的要求文字改变、来源缺失或解析失败时，提示重新核对，不继续套用原限值得出通过结论。检验要求文字校验并不替代客户图纸确认；例如导体电阻要求中的温度条件仍由检验人员确认。

## 本样表结果

24 个字段、21 条明细；11 条核对规则中 10 条通过，最终判定一致性为「待人工核对」。尾部开线、总长、导体电阻与扎线尺寸均在配置限值内，缺陷合计和允收数一致。SR、开关等 7 个项目未填写检验结果或判定，不能自动认定为不适用。定位列表指向这些待核对的结果与判定单元格，原报告的“合格”保持原样。

## 编辑规则

- 字段数据类型选择「测量值列表」，填写明确的分隔符；前缀、单位文字先使用“解析行／忽略内容”处理。空项、非数字、超大数、超过 100 个测量值会报解析错误。
- 公差模式区分「同一项目多次测量」和「不同部位」。前者共用一组限值；后者按照配置顺序一一对应，数量不符时提示人工核对。
- 核对字段使用稳定 ID 引用，可以按检验项目文字精确筛选对象记录；模板复制时同步更新引用。
- 系统不会修改报告单项或最终判定，不执行库存变动、自动放行、抽样标准查询、Cpk/SPC 或新增合格率指标。
- 重新上传或切换数据工作表后，必须重新确认核对提示。
- 已保存的测量值、核对结果和确认状态随验收单保留。业务备份版本 22 支持完整恢复；旧版本验收单默认没有核对确认。
