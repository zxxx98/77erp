# 生产任务单 PDF 与扫码登记

在「生产单」中打开一张单据，点击「导出 PDF」，下载可打印的 A4 生产任务单。

任务单包含单号、仓库、生产小组、成品名称与编码、规格单位、计划产量、配方信息、计划备料、备注和登记二维码。它用于下发任务，不包含累计产量、入库进度、实际耗料、登记历史、价格或成本。数据以导出时保存的生产单为准；后续修改计划或派组后应重新打印。

## 扫码使用

生产人员可用手机扫描纸单上的二维码打开系统，也可在系统「生产单」页面点击「扫码登记」。摄像头不可用时，可粘贴完整二维码链接，或使用键盘式扫码枪输入链接。

扫码打开后，系统校验当前账号权限、生产组、仓库和单号，并读取单据最新状态。符合登记条件时直接进入现有「生产登记」表单；未登录时先登录，再继续打开。扫码本身不会提交产量或扣减库存，员工仍需核对并确认本批登记。

未开工、待领料、已结束或已作废的生产单不能直接登记，页面会给出相应说明。本组生产人员不能通过二维码打开其他组的生产单；无组人员也不会因此获得访问权限。原有生产管理、仓库领退料和成品入库审批流程不变。

## 访问地址

二维码使用导出时浏览器中的系统地址。正式打印请通过员工手机可访问的地址进入系统再导出；在电脑 `localhost` 地址导出的二维码仅适合本机测试。浏览器内摄像头扫码需要 HTTPS（本机 localhost 测试除外）。

更换系统地址或将业务数据恢复至另一个系统后，应重新导出二维码。二维码只携带单据定位信息，不包含登录凭据，也不赋予操作权限。

## 维护说明

PDF 使用随服务端发布的开源中文字体，生成时不依赖外部字体服务。导出接口复用生产单读取权限，返回私有、禁止缓存的附件；PWA 的 API 请求仍采用网络读取。

本功能不改变生产单业务字段或登记写入接口，AI 工具不新增写入操作。现有 AI 生产单读取、成本过滤和生产组范围仍沿用原有逻辑，回归测试覆盖这些约束。
