# 工艺路线与工序登记

独立工艺路线按仓库维护，物料可选默认路线，BOM 可选覆盖。未配置路线的物料、旧生产单保持既有登记方式。新生产单保存根层及每个展开半成品层的路线版本与完整图快照，修改、停用路线不改写在制单。

每条路线为 1–50 个节点、最多 200 条边的无环图，必须有唯一最终产出节点；所有分支最终汇合。节点包含名称、作业说明、画布位置。桌面和手机均可在流程图中拖动节点，或切换工序列表设置前置关系；两端均可编辑。

流程图支持以鼠标位置为中心的滚轮缩放（40%–200%），按住空白处拖动画布；工具栏可放大、缩小或重置视图。手机/PWA可拖动空白处移动画布，并使用缩放按钮。拖动节点仍调整节点位置，缩放后拖线创建和右键/长按菜单保持正确的画布坐标；平移和缩放不会修改路线数据。

编辑流程图时，拖动左侧圆点到空白处松开，创建前置工序并连入当前节点；右侧圆点创建后续工序并从当前节点连出。拖线保留其他已有连线，不会自动插入原有流程。右键 A → B 的连线并选择「插入工序」，才会替换为 A → 新工序 → B；右键画布空白选择「新建工序」创建独立节点。手机 / PWA 对应长按连线或空白处。新节点自动选中，可在属性区修改名称；圆点也支持键盘 Enter / Space 创建。短按、取消拖动、在节点或画布外松开不会新增。独立节点和新增分支仍需通过前置关系汇合后才能保存。

桌面、移动 Web / PWA 的路线列表支持确认删除，无需先停用。删除需要 BOM 管理权限，并校验当前路线版本；被物料默认路线、BOM 覆盖路线或生产单工艺快照引用时禁止删除（包含停用档案和已作废生产单），可解除物料 / BOM 绑定或改为停用。删除不会清理关联记录或改变库存。AI 助手可说明删除入口与限制，不执行路线删除。

每层全部工序数量使用该层产出单位，不用原料单位冒充工序产量。串行按前序累计有效数量减去本工序已登记量放行；并行分支各自跟进，汇合取全部前序的可用共同数量。各半成品间的配比与可用量仍由原有 BOM 分层投入校验。

中间工序报工记录数量、作业员工、登记人、时间和说明，不扣料、不生成库存或产量。最终工序进入既有产出及实际耗料表单，工序记录与半成品/成品批次在同一事务内提交；任何旧入口也必须满足工序前置条件。只有根层产生待审批入库单。

默认作业员工为当前登录人。生产管理人员可以选择本单所属生产组的有效成员代报；登记岗位只能以本人登记，始终分别保存作业人与登记人。跨组、跨仓、过期版本、重复请求按现有权限及幂等规则校验。

中间报工可由具备生产管理和纠正权限者作废，但不能导致后序完成量超过前序；最终报工随对应产出批次作废，不允许独立作废。结束生产要求无未流转的工序数量；整单作废要求先纠正全部工序记录。备份、恢复、重置、仓库删除、更新通知、AI 只读解释同时覆盖新数据。AI 不新增工序或路线写操作。

## 使用步骤

1. 在「生产 → 工艺路线」新建路线，添加工序并设置前置关系；可以在画布连线或勾选前置工序，完成后保存。
2. 编辑物料，选择默认工艺路线。同一物料的多个 BOM 默认共用该路线；特殊配方可在 BOM 编辑页另选路线覆盖。
3. 新建生产单并按既有流程开工、领料。扫码或从电脑进入登记，选择生产层与工序，核对作业员工后登记本批数量。
4. 前序完成后登记后序；最终工序填写合格产出及实际耗料。半成品供本单上层使用，根层成品进入待审批入库流程。

工序记录支持分页查询和纠正。业务备份格式为 39，保存工艺路线、物料/BOM 绑定、生产快照、报工与作废事件顺序；仍可恢复旧备份。

## 父子 BOM 工艺总览

BOM 列表点击「工艺流程图」，可查看根 BOM 与明确展开的下级 BOM 的组合流程；编辑页在「工艺路线选择」区域提供相同入口，需先保存修改。各层依次使用 BOM 指定路线或物料默认路线；未配置、停用状态均明确显示。直接领用库存的物料不展开自己的 BOM。

图中每个 BOM 单独分组，实线保留工序的串行、并行和汇合关系；虚线从子件产出连接父 BOM 分组的供料入口。供料线不指定在哪道父级工序投入，不增加开工、报工或耗料限制。同一子 BOM 出现在不同路径时分别显示。

分层生产单详情提供「工艺总览」，只使用本单保存的路线快照与实际进度，后续档案修改不会改变在制单。点击「查看工序进度」进入该层原有登记页，返回时回到生产单详情；各层数量保留自身单位，中间工序数量不相加作为成品产量。

桌面默认流程图，手机与 PWA 默认分层列表，两种视图可切换。支持工序折叠、展开下一级、收起深层分支、进入分支、返回上层、物料/BOM/路径搜索及缩放；每页首先展示当前层和最多六个直属子层，可继续展开更深层，最多同时显示 24 个生产层，超出时进入分支查看。搜索结果保留祖先路径。长流程可用滚轮缩放（35%–150%）、按住空白处拖动查看，也可使用缩放按钮、滚动条或手机触摸滚动，并用列表查看完整工序和前置关系。

## 工序验收

桌面、移动 Web / PWA 均可在工艺路线的工序属性中选择「绑定验收模板」。只允许绑定当前仓库已启用、已发布的模板；不绑定时沿用原登记流程。新生产单在创建时将模板发布版本与名称写入各层工艺快照，旧生产单保持原状，后续发布或停用模板不改写在制单；创建新生产单时仍须确认绑定模板有效。

岗位新增独立的 `operation_accept`「工序验收」权限，不随品质管理或生产管理自动授予；管理员仍具备全部权限。仅生产作业岗位可在本组生产登记之外增加工序验收，仍只能操作已派给本组或本人的生产单，不因此开放品质管理、模板配置或其他生产单。

绑定模板的工序，登记人必须同时拥有原生产登记资格与工序验收权限。无权限点击登记时弹出「该工序需要验收，请通知验收员」，服务端在普通工序、最终产出及重试入口再次校验。该提示由操作者联系验收员，不会自动发送消息。作业员工与登记／验收人分别保留，代报仍按原生产权限规则执行。

登记本批数量后自动打开工序验收单，复用在线填写的表格／字段两种视图和模板校验。填写区清空样表值；点击「校验并预览」后须明确勾选「我已核对本批验收内容，确认验收合格」，再点击「验收合格并登记」。这里由验收员作出最终合格判定，系统不从任意字段文字猜测判定；模板系统核对发现差异或待确认项时禁止放行。第一版不增加待验收、返工或不合格品流程，不合格应取消登记并处理。

验收 Excel 由服务端按不可变模板和允许填写的单元格重新生成、解析及校验，不信任客户端预览；沿用品质文件存储配置。文件上传在数据库事务外完成，之后重新检查会话、岗位及派单权限。验收记录、工序报工和最终产出／耗料在同一事务内保存，失败回收本次未引用文件，重复请求不重复生成验收单。验收单自动绑定当前生产层物料，备注保存生产单、层级、总登记数量及作业员工。取消填写不保存验收单或报工。

工序历史可打开关联验收单；品质管理中也能查看、下载实际填写的 Excel。关联验收单及其生产单禁止直接删除，工序或产出批次作废时保留验收数据及关联作废状态；仅有已作废工序关联的验收单不再参与品质图表。业务备份 v44 新增工序验收单关联并验证仓库、模板版本及登记人，兼容旧备份；业务重置先清理生产关联，再清理品质数据。AI 保持只读解释，不代填或确认验收。
