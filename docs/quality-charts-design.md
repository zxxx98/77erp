# 品质图表

图表在桌面「品质管理 → 图表」统一配置。手机 Web / PWA 不提供品质管理入口和物料品质图表标签页。

## 分类与物料详情

- 普通图表：汇总同一模板的已保存验收数据，可按绑定物料分组或临时筛选物料。
- 物料图表：保存可复用规则，配置时没有当前物料。预览所选物料仅用于检查效果，不保存到配置。
- 桌面物料详情增加「物料信息 / 品质图表」标签页；品质图表需要品质管理权限。
- 当前仓库、已启用、物料分类的图表，在该物料有至少一个对应模板的已保存绑定 Sheet 时显示。没有对应数据就不列出，未绑定 Sheet 不参与物料图表。
- 日期筛选不改变适用图表列表；有历史绑定数据而所选日期无数据时显示空状态。停用物料的历史数据仍可查看。

## 配置流程

1. 填写名称，选择普通图表或物料图表。
2. 选择已发布模板。保存字段规则版本，后续读取同一模板字段兼容的历史和新增验收数据。
3. 选择 Sheet 普通字段（每个 Sheet 一条记录）或一个对象明细（横向对象逐行、竖向对象逐列各一条记录）。对象模式仍可引用 Sheet 普通字段，普通值会重复应用于每条明细，页面明确提示。
4. 配置横轴（日期、数字、字符串、单选、唯一 KEY）、日期按日/周/月汇总、可选分组、统计方式及数字字段。横轴不限时间；日期按周时以周一为起点。
5. 可配置独立的日期筛选字段，也可明确关闭日期筛选。图表样式支持折线、柱状、统计表。
6. 预览同模板全部已保存数据、单张验收单或模板样表，再保存。物料图表的正式数据预览需选择临时物料；样表可直接预览。允许无验收数据时先保存规则。

统计方式仅有求和、平均值、最小值、最大值、记录数。合格率等指标直接读取模板数字字段，不引入分子/分母或专用计算。单位按模板字段显示，例如解析为 95、单位为 `%`，显示 95%，图表不再乘以 100。Excel 本身的百分比显示值沿用模板解析规则。

## 数据一致性与追溯

- 正式统计仅读取已保存验收结果及其不可变模板版本，不修改验收原文件、物料、库存或校验状态。
- 同一 Excel 多个数据 Sheet 独立参与统计与物料筛选。
- 使用字段 ID 和属性 ID 引用，字段改名不会切断历史关联。用到的字段缺失、类型或单位变化，则整张对应 Sheet 不参与，返回数量并在页面提示；不会按名称猜测新字段。
- 按物料分组使用物料 ID，历史快照改名不会拆成两个物料分组，显示采用保存时的名称/编码。
- 空横轴、非法日期和空/非法数值跳过并计数；0 和负值有效。记录数不要求数值字段。
- 点击图表点、柱或统计表的「查看来源」，可追溯验收单、Sheet、对象行/列及统计原值，查看保存结果并下载上传原始文件。来源每页 50 条。
- 查看页支持全部或单张验收单、日期范围；普通图表还可临时按物料筛选。筛选不改变配置。
- 品质图表、物料图表、编辑预览及 AI 助手中的图表均可全屏查看，支持折线、柱状和统计表；桌面工作台趋势图也提供同一入口。全屏占满浏览器可用区域，适配手机横竖屏与 PWA；关闭按钮、Esc 或手机返回可退出，并保留原页筛选。正式数据图表在全屏内仍可查看来源。
- 长横轴标签自动换行并预留底部高度，完整显示文字。全屏显示当前图表的全部横轴标签，密集时横向滚动；数值、日期保持原有比例，过近标签错行排布，避免相互遮挡。普通视图保留标签抽稀，数据点不抽稀。
- 一次最多读取 2000 张验收单、统计 20000 条记录或 1000 个分组；超限明确报错，不截断统计。验收单超过 2000 张时应选择单张验收单；引擎级记录与分组超限可缩小日期范围。

## 保存、权限与备份

复用当前仓库和品质管理权限校验，跨仓库资源不可见。创建有操作幂等校验，编辑、启停、删除检查版本以防覆盖他人修改。图表启停不影响已保存验收数据。

业务备份格式升级到 21，包含 `quality_charts` 及其模板发布版本引用。恢复校验字段引用和仓库关系并更新编辑版本；旧格式恢复为空图表列表。业务重置清空图表规则，R2 原文件保留，连接和模拟存储方式不变。

AI 助手只增加功能说明，不增加未经设计的品质图表查询或写入工具。
