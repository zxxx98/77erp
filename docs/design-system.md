# 77 ERP 设计规范 · SaaS / Minimalist Modern

版本：1.0.1 · 保存日期：2026-10-03

## 风格来源

- 参考网站：https://www.designprompts.dev/
- 具体风格：https://www.designprompts.dev/saas/
- 参考站标识：`saas` / Tech Style / Minimalist Modern。
- 已读取参考站发布的风格说明，提取其 Electric Blue、留白、精细排版、浅色卡片和微交互原则，用于中文业务工作台。
- 本文件为本项目的内部应用规范，不是参考站原文。应用启动时将完整规范和设计令牌保存到 SQLite 的 `design_styles` 表，内部可通过本文件及 `/api/style` 查阅，业务界面不提供设计规范页面。

## 设计原则

清晰的结构，克制的细节。高频操作优先；一页一个明确的主操作。大数字表达经营状态，浅色卡片组织信息，蓝色用于动作和当前状态。重要数据保持可读，不使用装饰性大面积渐变。

## 界面文案

- 使用严肃、简洁的业务语言，直接说明功能、数据或操作结果。
- 页面标题使用功能名称，例如「工作台」「商品管理」「采购入库」「库存管理」。
- 辅助说明仅用于解释统计口径、操作步骤、状态和限制。
- 不使用宣传口号、押韵短句、情绪化欢迎语或推广标记。
- 按钮使用明确动作，例如「新建入库」「确认出库」「导出单据」。

## 字体与版式

- 界面：Inter / -apple-system / BlinkMacSystemFont / PingFang SC / Microsoft YaHei / sans-serif。无需外部字体服务。
- 业务界面的中文标题使用系统无衬线字体，优先保证汉字清晰；品牌数字使用更紧凑的粗体。
- 大标题 26px，关键数字 29px，正文 13–14px，辅助文字 12px。
- 数字采用 tabular-nums，金额保留两位小数。
- 桌面侧栏宽 224px，正文最大宽度 1600px，卡片间距 20px；窄屏导航收起为图标栏，指标和表单自动换行。

## 组件与交互

- 按钮：高度 36–40px，圆角 7px。主按钮蓝底白字，次按钮白底细边框。
- 表格：浅灰表头，行高约 64px，数据左对齐、数值右对齐。空状态提供可执行入口。
- 状态：淡色底 + 文字 + 小圆点，颜色之外也用文字表达。
- 表单：字段始终有标签；失败明确说明原因；提交中禁止重复提交。
- 弹窗：操作聚焦、Esc 关闭、键盘焦点限制在弹窗内、关闭后焦点恢复。
- 动效：150–200ms，仅用于 hover、淡入和状态反馈；遵守 prefers-reduced-motion。

## 业务约定

- 默认一个主仓库，支持新增及切换多个仓库；各仓库库存、成本和单据独立，商品可选择同步档案。商品用当前仓库内唯一条码定位，扫码仅使用手机摄像头，保留手动条码查询作为辅助。扫码入口不展示固定条码、示例商品或演示识别按钮。
- 新增商品的条码为选填，留空时服务端在同一事务中生成唯一的 `SKU-000001` 格式编码，自动跳过已被手动录入的编码；保存后可查看、扫码和下载标签。编辑商品时条码留空保留原条码，避免现有标签失效。
- 商品初始库存为 0，通过入库单增加库存；出库必须先校验库存。确认单据和库存变更在同一 SQLite 事务完成。
- 单据保存成交单价和商品名称快照，后续编辑商品不会改变历史单据。
- 演示数据仅在空数据库初始化一次。扫码成功不会自动改库存，用户确认单据后才提交。
- 手机浏览器摄像头需要 HTTPS 与浏览器授权（localhost 可用于开发）；手动条码查询不依赖摄像头。后续手机 App 可复用条码识别结果与入出库 API。
