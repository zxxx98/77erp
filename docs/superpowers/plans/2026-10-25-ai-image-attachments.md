# AI 图片附件实现计划

目标：桌面 Web、移动 Web / PWA 可选择或粘贴图片，预览、移除并发送给现有模型分析，重新打开对话后可继续查看和追问。

实现方式：沿用现有对话 JSON 和权限校验，文字保持字符串，新增独立 images 字段；仅在模型请求边界转成 Chat Completions 的 text/image_url 内容。图片作为压缩 data URL 随对话保存，不依赖公共图床，不接收外部图片 URL。

约束：JPEG/PNG/WebP，每次最多 3 张，原图每张最多 10 MB；浏览器压缩至最长边 2048、每张最多 1 MB，服务端独立检查真实图片格式并重新编码。每个对话最多 12 张，达到上限后提示新建对话。支持仅发图片及与表格一起发送，业务写操作仍需原有预览确认。

- [x] 添加共享限制与服务端图片校验，调整聊天请求容量、历史返回和模型内容转换；保留旧文本和表格协议。
- [x] 添加浏览器压缩与附件预览，接入选择/粘贴、删除、发送、失败恢复和新对话清理；沿用现有图片查看器与按钮样式。
- [x] 桌面、Pixel 7、iPhone 13 尺寸（含 PWA）验证图片选择、粘贴、预览、删除、发送和恢复对话，核对截图；运行 AI/API 测试与生产构建。
