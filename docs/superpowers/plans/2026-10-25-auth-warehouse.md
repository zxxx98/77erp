# 登录页 C 版仓储插画实施计划

**Goal:** 将用户已选定的 C 版落地为登录页左侧，采用浅蓝底、清晰标题和仓储插画。

**Architecture:** 保留 AuthPage 表单与鉴权逻辑，替换左侧流程卡片为独立装饰性图片。使用本地 WebP 素材、响应式图片和 CSS；手机/PWA 使用紧凑品牌区。

**Tech Stack:** React、CSS、Vite、Sharp（素材编码）、Playwright。

## 范围约束

- 用户已确认 C 版；右侧登录和首次初始化流程保持兼容。
- 桌面 Web、移动 Web/PWA 均验证；不涉及原生客户端。
- 保留仓库已有改动，按照 AGENTS.md 在 main 工作。
- 不改变业务字段或可写接口；AI 助手 schema、预览和测试无需同步变更。

## 素材来源

使用内置 imagegen，以已选定的 C 版预览为参考生成独立透明 PNG，再用 Sharp 转码为 WebP。

提示词：提取 C 版中的仓储插画，保留两组蓝色货架、牛皮纸箱、浅灰周转箱、前景托盘、蓝色搬运车、扫码枪和单据，等距 3D、哑光材质、柔和接触阴影。透明背景，不包含 UI、标题、品牌或可读文字，所有物体完整可见，3:2 横向画布和少量安全边距。
