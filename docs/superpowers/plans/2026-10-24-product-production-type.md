# 物料生产类型实施计划

**目标：** 物料新增生产类型：成品、半成品、原料；已有物料及未填写字段保持未设置。

**设计：** 使用 `production_type` 文本字段，空字符串代表未设置，三个有效值使用中文名称。共享校验保证接口、普通导入与 AI 导入一致。复用桌面、移动 Web/PWA 的现有物料表单，不改变生产单选料或库存记账规则。
