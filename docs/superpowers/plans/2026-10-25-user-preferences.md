# 用户习惯：空白处关闭

## 设计

设置增加“用户习惯”，提供弹窗、抽屉两个独立开关，默认均关闭。移动端统一底部面板采用抽屉开关，文案明确说明。配置即时生效，以版本化 localStorage 按账号保存；同源标签页同步，存储失败显示提示。管理员在工作空间设置中配置，员工在账户设置中配置，仅生产用户也提供入口。

共用 Modal 通过现有 onClose 关闭，保留业务自身的未保存和忙碌保护。只接受最顶层遮罩的点击，且按下位置必须在遮罩，避免拖拽误关。BOM 的独立 Drawer 接入抽屉偏好。Esc、图片预览、扫码保持现有行为。

## 实施与验证

1. 新增浏览器用例，先验证用户习惯入口缺失导致失败。
2. 新增账号级偏好 Context 和设置面板；App 挂载 Provider，设置与员工入口复用面板。
3. 共用 Modal 与 BOM Drawer 接入关闭偏好，补充必要样式。
4. 验证默认关闭、独立开关、持久化、跨标签同步、账号隔离、内容点击、拖拽、未保存保护、移动 Web / PWA。
5. 运行相关浏览器测试、单元/API 测试及构建，查看桌面与手机截图，检查 AI 同步范围；本次无业务字段或 AI 工具变化。

## 后续建议（本次不实现）

Esc 关闭开关、列表每页条数、表格紧凑度。跨设备账号同步可在确有需要时将偏好存储迁移至服务端。
