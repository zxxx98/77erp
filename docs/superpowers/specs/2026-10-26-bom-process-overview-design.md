# 父子 BOM 工艺流程与生产进度总览

用户已于 2026-10-26 确认本方案。

## 目标与入口

在现有桌面 Web、移动 Web 和 PWA 中增加组合流程图，沿用现有页面、配色、按钮和工序节点样式。

- BOM 列表的每条记录增加「工艺流程图」入口；编辑页工艺路线绑定区域也提供入口。有未保存修改时明确提示先保存，图展示已保存配置。
- 生产单详情的「分层生产」区域增加「工艺总览」，显示该单根层与展开半成品层的工艺及进度，保留「查看各层进度与批次」入口。

## 方案比较与选择

推荐按 BOM 分组的组合流程图：组内展示完整工序关系，组间展示供料关系。可以看到整体，又保留每层的名称、产出单位和归属。

简单地将所有工序串成一条线会丢失并行关系；允许手工把子件连接到父级特定工序则需要新增投入点配置与业务规则，本次不纳入。

## 流程图语义

1. 每个生产层是一个独立分组，显示产物名称、BOM 名称、路线名称及来源（BOM 覆盖或物料默认路线）。同一子 BOM 被不同路径引用时分别显示，节点标识包含完整层级路径。
2. 保留各条路线的串行、并行、汇合关系，以实线箭头表示工序先后。
3. 子 BOM 的最终产出节点通过虚线连接至直属父 BOM 分组的供料入口，并标注「供料」。不连接到某一道父级工序，不增加开工或报工限制。
4. 未配置路线的生产层仍保留产出节点，显示「未配置工艺路线」，保持上下层关系可见。
5. 仅展开明确选择「展开下级 BOM」的材料。直接领用的物料不展开其自有 BOM 或工艺，可在所属层材料说明中查看。
6. 图例明确区分工序前置与跨层供料关系；只有末道工序有效产出才计入该层完成量，不把中间工序数量相加当作产品产量。

## 两处数据来源

BOM 图读取当前仓库已保存的根 BOM、明确关联的下级 BOM 以及各自有效路线绑定，在一次读取快照内组装。显示停用状态；遇到关联缺失或无效结构时明确报错，不显示不完整的成功结果。支持无路线、单层、多层情况，沿用层数和节点数量上限。

生产单图只使用建单时保存的生产层与路线快照，叠加现有有效工序报工及每层产出数据。档案路线后续修改、停用不改写该图。历史未配置路线的层明确显示无工艺快照。各层数量使用各层单位，不汇总不同产物的数量或伪造全单完成百分比。

## 交互与规模

- 桌面默认展示按层排列的分组流程，支持缩放、恢复适配和分支折叠；点击工序查看说明，生产单可进入该层的现有工序进度页面。
- 手机和 PWA 默认展示适合窄屏的分层列表，可切换到同一流程图进行平移、缩放；点击操作无需悬停或拖拽才能完成。
- 大型 BOM 默认折叠深层分支，显示未展开层数，可逐层展开或按物料搜索定位，避免一次渲染上万个工序节点。
- 通过文字标识状态，提供键盘操作、加载、空状态、失败与重试反馈；图内部滚动不撑宽整页。
- 沿用现有中、英、越文案体系。

## 实现边界

新增只读 BOM 工艺总览接口，在现有 BOM 权限和仓库隔离下返回分层结构与路线；不在浏览器逐层请求，不更改既有写入接口。组合模型与展示组件供 BOM 和生产单复用，生产单继续使用现有快照数据。

本次不新增跨层工序执行约束，不改变耗料、库存、审批、路线编辑和报工规则，不添加数据库迁移或版本发布。提交前检查 AI 助手说明与只读解释是否需要同步，现有工具写入参数保持兼容。

## 验收

- API：多层、重复路径、默认与覆盖路线、未配置及停用路线、直接领用不展开、跨仓和权限限制、异常结构及容量上限。
- 图模型：串行、并行、汇合边保持准确，供料边连接直属父层，无节点 ID 冲突。
- 生产单：路线变更不影响历史快照；报工和作废后数量更新；各层单位和产出准确；旧单兼容。
- 浏览器：桌面、Android 浏览器尺寸、iPhone 尺寸及 PWA，覆盖两个入口、分支折叠、搜索定位、图与列表切换、进入工序详情并返回、窄屏无页面横向溢出。
- 完成相关 API 与浏览器测试及生产构建；实际查看桌面与移动截图，Safari 引擎无法运行时明确记录验证限制。

## 已确认决策

跨层连线采用「供料」虚线连接父 BOM 分组，不绑定父级某一道工序；本次完成总览展示，不新增投入点配置。
