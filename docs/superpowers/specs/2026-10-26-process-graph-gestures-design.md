# 工序流程图直接编辑

用户确认的交互：节点前后各有圆点控制器，拖线到空白处松开即创建并连接新工序；空白处右键创建独立工序；已有 A → B 之间插入 C 必须右键该连线，替换为 A → C → B。

- 左侧圆点创建新节点 → 当前节点，右侧圆点创建当前节点 → 新节点。保留其他连线，不隐式插入或改接旧分支。
- 拖动时显示预览线；短按、Escape、pointercancel、失去捕获、放到节点或画布外均不创建。节点本体仍可拖动。
- 右键空白显示“新建工序”，右键连线显示“插入工序”；触屏以长按打开相同菜单，滑动取消长按。菜单支持键盘、关闭与视口边界避让。
- 新节点在落点附近放置并避开已有节点，自动选中以修改名称。画布滚动后坐标仍正确。
- 新建和移动节点保留 24px 画布边距，以完整显示圆点；编辑器长名称最多显示两行，完整名称可在属性区查看。自动排列增加节点间距，并在最长路线中压缩列间距以保持坐标不超过 10000。兼容旧紧凑布局的圆点命中区域，避免遮挡相邻控制器及短连线。
- 圆点可用键盘 Enter / Space 在相应方向创建，工具栏和前置选择保留，便于列表模式操作。
- 只在路线编辑器提供写操作，路线预览与生产工序进度保持只读。遵守忙碌状态、50 节点 / 200 边限制。最终保存继续验证唯一产出及无环规则。
- 桌面、移动 Web 与 PWA 共用实现，三种语言同步；无数据格式、API、生产快照或 AI 写能力变化。

验证：纯函数覆盖增删边方向、插入、边界与限制；浏览器覆盖拖动、取消、右键、滚动坐标、触摸长按、保存后图结构与只读预览。
