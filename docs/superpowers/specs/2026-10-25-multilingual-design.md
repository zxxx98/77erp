# 三语言界面设计

用户已确认：简体中文、English、Tiếng Việt，登录页及所有应用外壳右上角提供国旗 SVG、语言名称、下拉箭头的切换组件，移动端紧凑布局，当前项有勾选。

- 桌面 Web、移动 Web、PWA 共用 i18next/react-i18next 词库，按业务模块维护稳定语义键。
- 切换语言不重新挂载业务页面、不清空表单或草稿。账户语言服务端保存，本地缓存；首次匹配浏览器，未知语言回退中文。
- 系统显示文字、组件库、日期数字格式、错误提示、AI 操作卡片和回复语言同步切换。用户输入和既有业务数据不翻译，币种/汇率/业务时区不随语言变化。
- API 保留现有 error 文本，新增稳定错误码/参数；业务判断不依赖翻译后文本。AI 工具字段名保持稳定。
- 系统生成导出/打印使用显式语言参数或用户偏好，原有导入表头保持兼容，用户模板原样保留。
- 语言资源打包并进入现有 PWA 预缓存。测试账户隔离、快速切换、表单保留、布局、离线和三语关键业务流程。
- 直接在 main 工作，保留两个既有浏览器测试文件和 .superpowers 中的未提交改动。
