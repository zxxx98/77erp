# 桌面生产登记抽屉

用户已确认：桌面从单据内进入登记时打开右侧抽屉；手机 Web / PWA 和扫码直达登记页维持当前设计。

- 复用通用 Modal 的 drawer 展示，宽 720px，受视口限制。背景单据保持挂载、标签页及滚动位置。
- 抽屉头部固定标题、单号和产品，底部固定取消 / 提交。中间独立滚动。
- 工序在上，选中后显示路线 / BOM / 层级、可报和已报数量及工序备注，再填写数量。去掉独立大卡片和重复数量标题。
- 工序超过六个时使用抽屉内可搜索列表，不嵌套选择弹窗；少量选项仍可直接点选。
- 工序选择器与数量输入框等高（44px）；选中名称单行省略，悬停显示完整名称，路线和层级另行完整展示。
- 复用登记校验、精确分数、验收和请求幂等性。提交失败保留输入，成功关闭抽屉并更新背景数据。重新读取仅刷新数据，不关闭抽屉。
- 关闭按钮、取消及 Escape 统一通过未保存提示；提交期间阻止退出。
- 不改变 API、业务字段和 AI 工具语义；提交前检查 AI 同步范围。

验证：桌面抽屉打开、选择、提交、失败、重读、关闭保护、固定底栏和背景恢复；桌面直达、iPhone、Android 和 PWA 原有登记测试；构建与相关单元测试。
