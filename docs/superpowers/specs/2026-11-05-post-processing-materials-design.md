# 后处理工序固定用料

用户已在会话中确认以下方案，按现有生产领料流程实现，覆盖桌面 Web、移动 Web 和 PWA。

后处理工艺的每道工序可以配置零到多种材料，每种材料填写每次用量。材料必须属于当前仓库、已启用，不允许重复；用量为正数并遵守数量精度及整单位规则。普通生产工序仍由 BOM 管理材料。

创建生产单时，绑定工序及本单成品系数，把材料身份、单位、整单位规则和每次用量保存为快照。后续工艺修改不影响历史生产单，单价同步也不更新材料。预计次数为计划成品数量除以系数向上取整，计划用料为预计次数乘每次用量。相同材料与 BOM 需求合并进入材料台账和初始领料申请，保留后处理需求明细。草稿仅计算需求，开始生产才申请领料，不自动批准或扣仓库库存。

后处理报工按本次正整数次数自动耗用固定材料，不增加成品、不生成成品入库单、不再次扣仓库库存。校验本单已领未耗未退余额，余额不足或材料已停用、单位变化时拒绝整笔报工。消耗金额按现有材料池成本规则分配，记录在对应报工中并汇总为后处理材料成本及本单总耗料成本；不回写此前已批准的成品入库成本。材料成本遵守现有财务权限。不同后处理及普通生产共享本单材料池，不重复计耗。

作废后处理报工恢复材料池数量和原成本，移除有效工资、释放次数，历史记录保留。余料沿用退料流程，额外生产耗料不足沿用补料流程；已确认的领料单不随计划更改自动改写。现有实际产量次数上限、尾数释放、完工条件和验收要求不变。无材料配置的已有后处理工序保持兼容。

验证覆盖配置校验、快照稳定、110/20 的备料和尾包、合并材料、部分领料不足、报工作废/重复请求、成本权限、普通/分层生产及备份往返。浏览器覆盖配置、建单、领料、报工和手机/PWA显示。AI 读工具、提示、字段及文档同步更新。保留当前登记抽屉的并行改动，只有本任务改动交付 main。
