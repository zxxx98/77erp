# 验收单导入与解析

2026-10-20 实现。沿用桌面品质管理入口，手机 Web / PWA 不开放。图表配置与展示已实现，详见 [品质图表设计](quality-charts-design.md)。

## 操作流程

品质管理分为「验收单」与「模板配置」。验收单列表支持按名称或单号搜索、分页、查看详情及下载上传原文件。

导入时选择已启用模板，显示其发布版本并下载该版本原始 Excel。用户填写后上传 `.xlsx`（最多 10 MB），勾选需要解析的数据 Sheet，浏览器 Web Worker 逐 Sheet 复用同一套模板规则，默认以紧凑列表展示 Sheet 名称、解析状态和物料绑定操作，点击“查看解析结果”后在弹窗中展示该 Sheet 的普通字段、对象明细、解析问题和系统核对结果。初次上传默认解析并勾选全部，说明页等非数据 Sheet 可取消；取消或重新勾选会即时过滤已解析结果，无需重新解析，至少保留一个。数据 Sheet 名称可以不同，也不必与模板样表 Sheet 同名。错误展示字段 / 属性、工作表及具体区域，点击可在上传工作表中高亮定位。在定位面板点击单元格后可编辑文本，点击“应用手动修正”重新解析，也可“恢复原始内容”。结构或合并区域问题仍需在 Excel 中修正后重新上传；页面修正不改写上传原文件。无解析问题才可确认保存；名称必填，备注可选。

确认保存后生成 `QA-YYYYMMDD-<12位随机十六进制>` 单号，记录名称、备注、提交人、保存时间、发布版本、解析结果与上传原文件。当前记录只读；不包含审核、编辑或删除；品质图表独立配置并引用已保存结果。

## 手动修正及来源标记

修正仅在导入草稿的定位面板提供，普通字段、对象明细、字段标题或属性表头均可修正文本，合并单元格只能修正左上角。每个单元格保留一份相对上传原文件的最终修正，恢复原值会移除该标记；重新上传或切换模板会清空修正。同一文件取消勾选 Sheet 时保留草稿修正，保存时仅提交所选 Sheet 的修正。

浏览器在 Worker 中重新读取原文件并应用修正，清除被修正格的数字、日期、公式缓存状态，再执行完整模板解析及系统核对。修正不会绕过必填、数据类型、标题及合并结构校验；存在问题仍阻止保存。受影响 Sheet 的物料自动匹配建议会刷新，用户手动选择的物料保留，系统核对确认会重置。

保存接口额外接收 `corrections` JSON 数组，每项为 `{sheetName,address,text}`，最多 1000 格，每格文本最多 10000 字。服务端从上传原文件重算原值并应用修正，不信任客户端解析结果和原值；修正参与请求幂等校验。修正记录存入解析快照各 Sheet 的 `manualCorrections: [{address,original,text}]`，不新增数据库列。快照、解析单元格与详情显示“手动修正”及原值 / 修正值，由验收单提交人和保存时间确定确认人及时间。图表读取修正后的已保存解析值，原文件下载保持字节不变。备份恢复会重新应用修正并比对完整结果和来源记录，旧记录无修正时保持兼容。

## 每个 Sheet 的物料绑定

解析结果的每个 Sheet 提供独立的物料绑定开关，默认开启，用户可取消绑定。开启后必须成功自动匹配或手动选择物料才能保存，关闭后不要求选择物料。切换模板或重新上传后重新解析并生成匹配建议，不沿用旧文件的绑定；同一文件内取消再勾选 Sheet 会保留已选绑定。

唯一 KEY 按显示文本读取，精确匹配当前仓库已启用物料的编码（`products.barcode`）、名称或客户料号。三个字段共同查找，仅命中一个不同物料时自动绑定；多个字段指向不同物料、同名或不同客户料号命中多个物料时均转为手选，不设置猜测优先级。不配置唯一 KEY、空值、解析有误或没有匹配物料时提供手选。唯一 KEY 配置在对象属性时，非空值全部相同才可用于 Sheet 自动匹配；有多个不同值时不取第一条记录，要求手选整个 Sheet 对应的物料。

手选支持按编码、名称、规格和客户料号搜索，分页展示当前仓库已启用物料的编码、名称、规格和单位；品质权限即可使用，不返回财务字段。自动匹配结果可手动更换，取消绑定后也可重新开启。

保存只接收各 Sheet 的 `mode`（auto / manual / none）及 `product_id`，服务端重新校验 Sheet 完整性、物料所属仓库与启用状态；自动模式还需再次匹配，发生冲突时要求重新解析或手选。上传原文件后在事务内再校验一次，以覆盖物料被停用、删除或自动匹配变化的竞态。绑定选择参与保存请求幂等校验，不信任客户端提供的物料快照。

`quality_acceptances.bindings` 独立保存每个 Sheet 的名称、模式、原始唯一 KEY 值、物料 ID，以及保存当时的名称 / 编码 / 规格 / 单位快照；不改写解析快照，也不更改物料库存或周期校验状态。详情按 Sheet 展示保存的物料快照。已绑定验收单的物料禁止删除，可停用保留历史。既有 SQLite 数据启动时增加默认值为 `[]` 的列，旧验收单保留未绑定状态。

## 解析与版本

模板仅配置单个 Sheet 的一套规则，不提供按 Sheet 分别配置规则。导入时将所选发布版本的规则和固定区域分别应用到每个选中的数据 Sheet，忽略草稿变化。不推断值区域，也不自动扩展对象行列；空记录跳过，部分填写记录保留并逐属性校验。数字、日期、单选、多选沿用模板的转换规则，公式需要 Excel 缓存结果。

读取前逐 Sheet 比较模板样表的字段标题、各属性表头及配置区域的合并结构；多级表头同时校验上级分组和末级表头原文，修改属性显示名称不影响原表头校验。任一选中数据 Sheet 存在问题，均阻止整份验收单确认保存；错误包含原数据 Sheet 名称及具体位置。未选中的 Sheet 不解析，仍完整保留在上传原文件中。新增、移动或改写相关结构会列出问题；配置区外的内容不参与结构比较。读取值可以改变，模板原文件不改写。

浏览器先查询已发布模板的定义与样表，再在 Web Worker 中读取本地 Excel、解析所选 Sheet 并核对。预览阶段不上传原文件，只将唯一 KEY 发给服务端查询当前仓库的物料匹配建议。模板编辑的初次 Excel 读取也在浏览器完成。读取和解析规则与服务端共享，保留文件、解压大小、单元格及结果大小限制。

新页面保存不依赖预览凭证，没有 15 分钟时限，服务重启不使本地预览失效。更改 Sheet 勾选只过滤已解析结果，不重新读取或解析文件；重新上传文件才重新解析。确认保存时上传原文件，服务端重新解析并校验权限、当前模板版本、字段规则、物料绑定与核对确认，不信任客户端结果。模板停用或发布版本变化时要求重新选择模板并预览，存储期间再次检查以避免竞态。旧版预览接口及其签名凭证校验保留兼容，已打开的旧页面仍遵循旧凭证有效期；刷新后使用本地预览。

保存使用用户与仓库隔离的请求标识，重复请求返回已保存记录。即使后来模板停用或凭证过期，已经完成的同一保存请求仍可安全重试。新发布版本、草稿修改及停用均不改变已保存记录或其版本关联。

## 存储与集成

- `quality_acceptances`：仓库、单号、名称、备注、模板 ID、不可变发布版本 ID、上传文件 ID、服务端解析快照、提交人及时间。
- 上传文件复用 `quality_template_files` 的不可变 Excel 引用和工作簿快照结构；对象键为 `<excel_prefix>/<instance_id>/acceptances/<uuid>.xlsx`，模板原表保留在 `templates/` 下。
- 原文件使用现有 R2 连接；预览不写入存储。确认时原文件写入成功后提交记录；事务失败回收本次未引用对象。下载验证仓库权限、原始大小及 SHA-256，返回完整上传字节，保留图表、格式和公式。
- 沿用 `quality` 权限，所有接口再次验证有效会话与当前仓库。验收单变动更新仓库数据版本；有验收单的仓库不可删除。
- 业务备份当前为 v22，保存验收单系统核对确认状态；v21 增加品质图表，v20 新增逐 Sheet 物料绑定及快照。兼容 v19 多 Sheet 结果、v18 单 Sheet 验收记录和 v17 模板备份；v21 及更早备份恢复时核对确认状态默认为未确认，v19 及更早备份默认未绑定。恢复校验版本 / 仓库 / 文件关联、解析快照一致性，以及绑定 Sheet、物料所属仓库和快照结构。业务重置先删除验收单再删除模板，不删除外部 Excel 对象。
- AI 助手提示同步明确：验收单须在桌面品质管理页面完成上传、解析、确认；当前未开放品质查询或写入工具，不将验收明细自动转为物料或库存单据。

## API

| 方法 | 路径（前缀 `/api/quality`） | 用途 |
| --- | --- | --- |
| GET | `/acceptance-templates` | 当前仓库已启用模板的发布名称、版本和原文件名 |
| GET | `/acceptance-templates/:id?revision_id=…` | 查询当前发布版本定义和样表，用于浏览器解析 |
| POST | `/binding-suggestions` | 查询各 Sheet 唯一 KEY 的物料候选，保存时再次验证 |
| POST | `/acceptances/preview` | 兼容旧客户端： multipart 原文件、模板 / 版本 ID、`sheet_names`（JSON 数组或 `*` 表示全部），逐 Sheet 预览校验、物料匹配建议及签名确认凭证 |
| POST | `/acceptances` | multipart 同一原文件、同一 `sheet_names`、确认凭证、名称、备注、请求标识、`bindings`（逐 Sheet 的选择 JSON）、可选 `corrections`（手动修正 JSON）；确认保存，旧客户端省略绑定时默认未绑定 |
| GET | `/products?q=&offset=` | 当前仓库已启用物料搜索，每页 20 条，不返回财务字段 |
| GET | `/acceptances` | 分页和搜索已保存验收单 |
| GET | `/acceptances/:id` | 发布版本、已保存结果、元数据 |
| GET | `/acceptances/:id/download` | 返回上传原文件 |

模板文件下载复用 `/templates/:id/revisions/:revision/download`，其中 `revision` 参数为不可变发布记录 ID。

## 验证

API 覆盖各类型、横竖对象、错误坐标、结构差异、确认凭证篡改 / 过期 / 跨用户与仓库、版本竞态、存储失败回滚、幂等、原文件字节一致性、历史结果不变、备份恢复及旧备份兼容。浏览器覆盖下载 → 上传 → 预览 → 保存 → 历史详情与下载、错误定位 / 重新上传、版本变化后重新解析，以及原有模板配置和手机无入口回归。

## 兼容与结果结构

模板仍使用 `schemaVersion: 1, sheetName, fields`。新网页导入显式发送 `sheet_names`；未发送该参数的旧客户端继续按模板样表同名 Sheet 解析，保持原接口行为。

新验收结果的 `schemaVersion: 2` 只标识数据解析结果格式，与模板规则版本无关：`sheets` 数组包含每个实际数据 Sheet 的 `sheetName/results/value/issues`，顶层 `value` 按 Sheet 名称分组，`issues` 汇总所有 Sheet 的问题并附上来源名称。同名字段在不同 Sheet 中独立保存。旧验收记录的扁平结果保持原样，历史详情、备份与恢复兼容两种结构。
