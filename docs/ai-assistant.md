# AI 助手

桌面侧栏和移动 Web / PWA「更多」提供 AI 助手；管理员在「系统设置 → AI 助手」配置。默认关闭，员工需要单独授予「AI 助手」权限。

## 部署与配置

服务端使用支持 Chat Completions 工具调用的兼容接口。若响应提示缺少 `choices[0].message`，通常是配置了 Responses API 地址，而当前集成只支持 Chat Completions，请调整基础地址为兼容接口的 `/v1` 基础路径，基础地址通常以 `/v1` 结尾，程序追加 `/chat/completions`。模型必须支持 `tools` / `tool_calls`，请求使用 `max_completion_tokens`。不同兼容服务的参数支持情况需要实际测试；不依赖 MCP 服务。

1. 生成32字节随机密钥，例如 `openssl rand -hex 32`，通过部署平台的密钥管理或环境变量 `AI_ENCRYPTION_KEY` 传给 Node 服务。不要提交到仓库。Docker 可通过 `--env-file` 注入。
2. 重启服务，进入 AI 设置，填写 HTTPS API 基础地址、模型名和 API Key。
3. 保存并测试连接，启用助手；按需开放写操作、设置每人每天请求数（UTC 日期，默认100）。
4. 在用户管理中授予员工「AI 助手」及相应业务权限。

API Key 用 AES-256-GCM 加密保存在数据库，网页不会读到原始密钥。更换服务地址必须重新填写 API Key，避免把旧服务凭据发送给新地址。加密密钥需独立安全备份；替换或丢失后，必须重新填写 API Key。连接测试使用实际模型调用，可能产生费用。

## 支持的场景

- **物料档案计数**：询问“当前仓库有多少种物料”时，按选定仓库实时统计全部物料档案，并分别返回启用、停用数，不受搜索返回条数限制。
- **校验补录**：已到期物料可指定实际校验日期（默认今天，可选过去日期）生成“已校验”预览，需「物料管理」权限。确认后记录所选日期，下次日期从实际校验日期按配置周期顺延；无周期时需提供晚于实际校验日期的下次日期。预览与确认使用同一实际校验日期。
- **跨库物料数量对比**：例如“对比主仓库和B库条码为 ABC-001 的物料数量”。工具通过同步关联或条码确认同一物料；重名由助手询问核对。未建档返回“未建档”，不会当作库存0；单位不同不计算差值。当前仓库访问规则与现有 Web 一致：登录用户可访问各仓库，并没有新增独立仓库授权体系。
- **批量采购入库 / 销售出库**：提供物料、仓库、往来单位、数量和单价。每批最多20张单据、合计100行，支持多个仓库及入出库混合批次。预览显示每笔单价、金额、库存变化；确认后整批在一个数据库事务中执行，任一失败全部回滚。批次多次涉及同一物料时按顺序累计显示库存。
- **仓库调拨**：例如“从主仓库调拨 ABC-001 物料10个到B库，原因是门店补货”。每次1–100种物料；预览展示两边库存变化、目标物料名称和条码，以及是否新建目标档案。确认复用现有调拨服务，原子生成调出/调入关联单据并转移库存成本。目标匹配存在冲突或两边单位不同会拒绝；任一侧相关库存或档案变化需重新预览。暂不开放AI撤销调拨。
- **库存盘点**：例如“主仓库 ABC-001 实盘总数是8个，原因是月末盘点”。每次单仓1–1000种物料，预览展示账面数量、实盘数量及差额。实盘数必须由用户提供，可为0，不能把增减量当总数；未列出的物料不调整。服务器记录预览时的库存，确认发现变化会拒绝。盘点批次及当前操作人通过AI审计关联，复用原有库存计价和通知逻辑。
- **Excel / CSV 新增物料档案**：上传 `.xlsx` 第一张工作表或 UTF-8 CSV，最多5MB、1000行、40列；向助手说明数量是否为期初库存。AI识别列对应关系，服务器读取完整表格生成预览，AI不能用生成内容替换原始单元格。支持名称、条码、分类、单位、采购价、销售价、安全库存、期初库存、规格、备注。名称、单位必须映射；缺失分类默认为“未分类”，缺失数字默认为0，条码留空自动生成；所有默认值均在预览中展示。已有条码拒绝导入，不覆盖物料。条码须使用文本格式保留前导零；不能恢复 Excel 已丢弃的前导零。

第一版表格导入工具用于**新增档案及期初库存**，不是现有物料库存覆盖工具，也不把上传表格自动转换成任意规模的入出库批次。现有物料批量入出库通过明确的出入库明细生成预览。单据查询目前提供指定仓库最近20张单据的基本信息。

## 用料清单与备料测算

同时具备「AI 助手」和「用料清单」权限时，可查询当前仓库已有 BOM、查看成品及材料配方，并按明确的生产数量测算备料。例如：“查找桌子的用料清单，再按生产 10 张测算缺料。”同名成品先核对编号。工具仅读取现有单层清单和当前账面库存，分数用量按原比例计算，仅最终材料需求向上保留 6 位小数；助手优先展示返回的 `quantity_fraction`，生产快照对应 `base_quantity_fraction`，不使用兼容小数重新推算。分数代表标准分摊量，不自动整箱取整。未预留、领料或扣减库存，不生成写入卡片，也不维护 BOM。关闭 AI 写操作后仍可查询。详见 [用料清单说明](bom.md)。

## 生产单查询

同时具备「AI 助手」和「生产单」权限时，可使用 `search_production_orders` 搜索当前仓库真实生产单、按待生产／已完工／已作废筛选，使用 `get_production_order` 查看建单配方快照、计划产量、实际耗料和合格成品。不返回财务成本，不产生写入卡片，关闭 AI 写操作后仍可查询。创建、编辑、完工和作废须在生产单页面核对执行，助手不能用采购、销售或盘点替代生产记账。详见[生产单说明](production.md)。

## 品质图表推荐与配置

需要同时具备「AI 助手」和「品质管理」权限，桌面及移动 Web / PWA 均可在助手中使用。例如：

- “看看当前仓库的验收数据，推荐可以生成哪些图表。”
- “用出货检验模板生成按月的合格率折线图。”
- “用采购验收模板的明细，按项目统计数量，生成柱状图和明细表。”

助手先查询当前仓库已发布模板，再读取字段编号、数据类型、单位、非空数量及最多5个字段样本，结合已保存的验收数据推荐候选图表。同名模板需核对编号；没有验收数据时明确提示，不把模板样表当作实际验收结果。每个模板最多读取2000张验收单，与现有图表取数上限一致；图表推荐不会保存配置。

支持普通图表和物料图表，以及折线图、柱状图、明细表。数字字段支持求和、平均、最小值和最大值，也可按维度统计记录数；可设置对象明细来源、分组及日期汇总。按工作表统计与按对象明细统计在卡片中明确展示，合格率直接取已有数字字段，不推算公式。物料图表保存可复用配置，按当前物料的绑定验收数据取数；指定物料可预览，未指定时不会混合各物料生成预览。

生成配置后，卡片显示模板版本、横轴、统计口径、分组及最多20项实际数据预览，并可展开查看配置 JSON。点击“确认保存图表”后，配置保存到品质管理图表列表；模型不能代替用户确认。确认前模板版本资料或验收数据变化时需重新预览。关闭 AI 写操作仍可查询和推荐，但不能生成保存卡片。助手不创建、修改或删除验收模板与验收单。

## 权限、确认与审计

- 当前用户取自服务端登录会话；模型不能指定操作人。工具执行前、模型响应后、确认时都会检查会话及权限。权限变化后旧对话不可继续读取或确认，需开始新对话。
- 入库要求采购权限，出库要求销售权限，物料导入沿用现有 `data_io` 权限；调拨要求 `transfer`，盘点要求 `stocktake`，不额外要求采购或销售权限。AI使用权限不增加业务权限。库存查询工具不返回库存成本，单据查询不返回财务信息。
- 所有写操作仅生成预览，只有网页确认接口可提交；模型没有确认工具。预览绑定用户，15分钟内有效。确认读取服务器保存的内容，不接受客户端改写明细。库存或相关业务资料变化要求重新生成出入库、调拨或盘点预览。
- 单据 `created_by` / `created_by_name` 仍为当前用户。`ai_actions` 保存完整预览、实际执行内容及结果；`ai_audit` 保存当前用户、工具、调用状态、确认时间及关联单据。成功审计与业务写入在同一事务内提交。设置页可查看最近100条审计记录。
- 重复确认同一预览返回原结果，不重复入库或开单。刷新 / 重新打开助手会恢复当前浏览器标签页最近对话；浏览器仅存对话ID，内容仍需联网鉴权读取。离线不能发送或确认。
- 每用户同时只处理一个对话请求，每次最多6轮、每轮最多8个工具调用；模型请求超时30秒，响应最多256KB。每日限额统计对话请求次数，不是 token 或费用预算。

## 数据及运维边界

对话文字、查询所需业务数据、表头及前5行样本、品质字段概况及图表候选统计发送给管理员配置的模型服务。完整表格留在本系统执行导入；对话历史会继续发送给同一配置的模型。上传资料和工具结果按不可信数据处理，不提供 SQL、脚本、任意 HTTP 或修改权限工具。

AI设置、对话及审计不包含在现有“业务备份”JSON中。完整 SQLite 备份可保留这些数据，加密密钥需另外备份。业务重置及备份恢复会使旧对话和待确认操作失效，需要开始新对话，历史AI审计保留用于追溯。当前没有自动清理对话的保留期策略，应纳入数据库备份、容量及访问管理。

验证方式：`node --test tests/ai.test.js` 使用可控模型响应验证权限、跨库对比、批次原子性、幂等、数据变化、表格映射与完整行导入；`npx playwright test tests/browser/ai.spec.js tests/browser/ai-quality-charts.spec.js` 使用测试模型接口验证桌面及移动浏览器的配置、Excel上传、预览、确认、恢复对话及调拨和盘点确认。测试不使用真实模型密钥，不代表某个服务商或模型的识别准确率验收。

工具调用协议参考：[官方 Function calling 文档](https://developers.openai.com/api/docs/guides/function-calling)。

## Web 对话界面

桌面侧栏展示当前用户最近50个对话；手机 Web 通过历史按钮打开列表。历史跨仓库展示，继续提问时以顶部显示的当前仓库为准；权限变化后不显示旧权限下的对话。

首页快捷提问填入输入框，编辑后发送。支持 Markdown 表格、列表及代码块，回复可复制；不执行模型返回的 HTML。添加表格入口支持 Excel / CSV，附件可移除。Ctrl / Command + Enter 发送，Enter 换行；所有库存写操作继续通过预览卡片确认。

确认卡片和图表预览随生成它们的那轮回复展示，后续消息接在该轮之后。确认成功后大卡片自动收起为简短结果，可通过“查看操作详情”或“查看图表与详情”重新展开，图表仍可全屏查看。刷新、切换历史对话或升级后重开旧对话时，卡片保持原有轮次；继续发送消息仍会取消上一轮未确认预览。
