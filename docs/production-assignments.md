# 生产单指派

桌面 Web、移动 Web 和 PWA 共用生产单详情「概览 → 生产指派」。生产管理人员可同时勾选多个生产组和个人，点击「派工」保存。个人候选仅包含已启用且具有生产管理或生产登记权限的账号；不要求先加入生产组。

待生产且无作业记录的单据可以调整或清空名单。开始生产后（含待领料、部分领料、已有批次或工序报工）可以继续追加多个组或个人，已有指派保留。已完工或已作废单据不能派工。追加不改变计划数量、材料申请、库存、成本和历史作业记录。

生产登记人员可查看、扫码进入并登记派给所属组或本人的生产单；指派本身不会授予生产权限。生产管理人员可代本单任一已指派组内员工或已指派个人报工。各组共用原生产单的产量、工序和物料余额，不分配独立额度。分组登记批次保留登记人所属的受派生产组，个人登记且不属于受派组时不标记生产组。

API 使用 `production_group_ids` 和 `user_ids` 完整提交名单，返回 `assigned_groups`、`assigned_users`（含编号与名称快照）。`production_group_id`、`production_group_name` 保留首个组以兼容旧客户端。已开工单的名单必须包含全部已有指派；版本校验、请求幂等和权限限制继续生效。

业务备份格式升级为 41，旧备份恢复后保留原单组指派。同一实例恢复保留仍存在的指派对象；跨实例恢复清除账号和组关联，避免相同数字编号错误授予访问权限。AI 助手可只读查询全部指派信息，不能执行派工。
