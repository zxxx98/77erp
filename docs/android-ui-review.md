# Android UI review · 1.1.1

日期：2026-10-03。范围：React Native 业务页面、CameraX 扫码页，Android 12+、ARM64。

本轮先修改界面，再独立检查最终源码、React Native 0.81.5 的键盘 / 弹窗实现、Android 安全区和回归测试。以下结论属于源码审查、组件交互验证和云端构建验证；没有用 Web 截图替代原生验收，也没有运行本地 Android 编译。

## 发现与修复

| 优先级 | 触发条件与原问题 | 最终处理 |
| --- | --- | --- |
| P1 | 短横屏 / 大字体时，固定底部操作占据大部分表单，输入和确认难以到达 | 按安全区可用高度、字号和键盘状态选择底部操作位置；受限时操作跟随表单滚动，编辑状态保持 |
| P1 | 边到边窗口可能不被 `adjustResize` 缩小；只依赖系统调整仍可能被键盘遮挡 | review 后统一使用位于窗口根部的 `KeyboardAvoidingView` padding 策略，只补偿实际剩余遮挡；已缩小的窗口补偿为 0，避免原 height 策略重复扣减 |
| P1 | 长单据在底部提交失败，错误显示在不可见的顶部；连续相同错误不会重新定位 | 弹窗统一显示错误并滚回顶部，每次错误增加修订号，即使消息相同也重新定位 |
| P2 | 窄屏商品行同时挤入名称、条码、库存、金额 | 名称与标识放在上方，分类 / 状态和库存 / 金额分别换行；列表名称最多两行，详情完整显示，可访问性标签保留全名 |
| P2 | 双列表单、双按钮在大字号下拥挤或溢出 | 共享 Columns 根据字号增加列基准宽度，由 Yoga 按实际容器宽度换行；按钮文字可换行，字段标签保留在输入框外 |
| P2 | 密码眼睛图标绝对定位，可能盖住文本 | 输入框与 48 dp 切换按钮分别占位；提交时同步禁用 |
| P2 | 大额统计、往来单位和金额互相挤压，详情键值横排不适合长分类 / 单位 | 指标卡响应式排列，金额不自动缩小；单据金额独立一行，商品详情标签和值上下排列 |
| P2 | 弹窗只有上下安全区，横屏刘海可能盖住控件 | 每个弹窗有独立 SafeAreaProvider，四边均应用安全区 |
| P2 | 放大的底部导航可能与绝对定位提示重叠，键盘弹出时占用输入空间 | 提示改为普通布局；键盘可见时隐藏导航，收起后恢复，标签文字居中且允许换行 |
| P2 | 网络错误固定在列表上方，大字体下挤占可用高度 | 同步错误及重试按钮放入各页滚动内容，首次加载失败也可滚动 |
| P2 | 扫码页使用像素间距，不处理刘海，横屏大字号控制区遮盖预览 | 间距换为 dp，合并系统栏和 cutout inset；控制区最多占可用高度一半并可滚动，取消按钮放在控制区开头 |
| P2 | 辅助文字与白底对比度约 3.62:1 | 同色系加深至 #647084，白底约 5.01:1，页面底色约 4.71:1；Web 主色和卡片风格保留 |
| P3 | 图标按钮仅 44 dp、新增商品用箱子图标、超长分类筛选横向跨度过大 | 图标按钮与筛选项至少 48 dp；新增使用加号；分类筛选限制宽度和两行，全名仍提供给读屏 |
| P3 | 查不到商品也提示打开相机权限设置 | 仅权限相关错误显示系统权限入口 |

## 验证与限制

`mobile/__tests__/adaptation.test.tsx` 增加 14 项回归检查，与既有用例合计 28 项：

- 模拟 320 × 480、800 × 360、360 × 800（2 倍字号）、1024 × 600（1.3 倍字号），检查受限空间下按钮进入滚动内容。
- 模拟底部安全区变化、键盘显示 / 隐藏、旋转，检查字段值和提交载荷不丢失。
- 使用真实 React Native KeyboardAvoidingView 逻辑，注入布局及键盘事件（含窗口顶部偏移）：完整窗口补偿遮挡，系统缩小窗口后不重复补偿，键盘隐藏后恢复。
- 连续相同校验失败均发出滚回顶部的请求；保存期间返回按钮和硬件关闭均无效。
- 密码切换保持输入，搜索时隐藏导航并在键盘关闭后恢复选中标签及查询。
- 长名称 / 分类详情不截断、数量与单价可访问性标签不混淆、权限错误入口正确。

组件测试不执行 Android 字形测量、Yoga 像素布局、系统输入法或相机预览，因此不能单凭这些测试宣称不存在设备上的文字裁切或遮挡。原生编译、Release Lint、签名、API 31 最低版本和 ARM64 产物检查由 [GitHub Actions](https://github.com/zxxx98/77erp/actions/workflows/android-release.yml) 完成。

## 真机验收清单

| 场景 | 操作与期望 |
| --- | --- |
| Android 12 与 Android 15/16，320 / 360 dp 窄屏，默认 / 最大系统字号 | 浏览全部五个标签及详情；业务文字可读，按钮完整可点，金额可查看完整值 |
| 竖屏、横屏、分屏，手势导航 / 三键导航，有侧边刘海 | 返回、扫码、底部按钮避开系统栏和刘海；横屏滚动可到达最后一个控件 |
| 登录 / 设置 / 商品 / 多商品单据，切换数字和文字键盘 | 当前输入框可见，滚动可到达提交按钮；关闭键盘没有残留大空白，输入数据不丢失 |
| 长商品名、100 字分类 / 单位、长条码、大金额、多行备注 | 列表保留可识别信息；详情完整显示；输入框、金额和删除按钮不互相覆盖 |
| 多商品出库，滚到底部，重复提交库存不足数量 | 每次均回到错误提示；更正后正常确认，保存期间无法重复提交或关闭 |
| 扫码页横屏与大字号，允许 / 拒绝相机权限 | 预览保留空间，取消可达；成功返回原生页面，拒绝后能手动查询 |
| TalkBack 与外接键盘 | 控件名称明确，禁用状态可读，输入框可区分，焦点可以到达全部操作 |

当前环境未连接可用 Android 设备，以上真机项目尚未执行。源码复查未发现仍未处理的 P1 / P2 问题；实际渲染和机型差异仍以此清单的设备验收为准。
