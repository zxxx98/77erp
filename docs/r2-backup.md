# Cloudflare R2 数据库备份

管理员在「系统设置 → 备份与恢复 → Cloudflare R2 自动备份」配置。桌面 Web、移动 Web 和 PWA 共用此配置。

1. 在 Cloudflare 创建私有 R2 存储桶，获取 Account ID。
2. 创建仅限该存储桶的 R2 对象读写 API 凭据，填写 Access Key ID、Secret Access Key。使用标准账户端点 `<Account ID>.r2.cloudflarestorage.com`；当前不支持司法辖区专用端点。
3. 填写目录前缀、五段 Cron 和 IANA 时区，保存后点击「立即备份」验证连接，再启用定时备份。例如 `0 2 * * *` 配合 `Asia/Shanghai` 表示北京时间每天 02:00；`0 * * * *` 表示每小时。
4. 如需通知，在「通知设置」启用 Webhook 并勾选「数据库备份」。备份成功和失败均走现有通知队列、签名及重试流程，不受仓库筛选限制。取消勾选或关闭通知总开关即可停发。

服务每 15 秒检查计划，仅执行当前计划分钟内的任务；停机错过的计划不补跑，重启后从下一次计划开始。同一服务进程不并行执行备份。手动备份直接在页面显示结果，不保存备份执行历史；勾选通知时，发送记录由现有通知流程管理。修改配置不影响已开始的任务。

桌面「品质管理」的验收单原始 Excel 复用此处的 R2 账户、存储桶和访问凭据。独立填写「Excel 目录前缀」，默认 `excel`，不能与备份目录相同；Excel 直接存入此前缀，不拼接备份目录，也不参与 SQLite 备份轮转。修改 Excel 前缀只影响新上传，旧文件按数据库保存的位置读取。关闭定时备份不会关闭 Excel 上传下载。

使用 Node SQLite 在线备份接口生成一致的 `.sqlite` 文件，上传后清理临时文件。运行用户需有足够的临时磁盘空间，进程被强制终止时可能遗留 `77erp-backup-*` 目录。每次成功上传后，自动保留当前目录内最新 10 个备份（按 R2 最后修改时间排序，并始终保留本次上传），删除超出的旧备份。仅处理当前目录中符合本系统命名格式的 SQLite 文件，不处理子目录及其他文件。不同 ERP 实例应使用不同目录。上传失败不清理；清理失败会在手动执行结果及已启用的备份通知中提示，下次成功备份后再清理。R2 凭据须包含列举、上传和删除对象的权限。未完成分片仍可通过 R2 生命周期规则清理。


完整数据库包含用户、密码哈希、会话、业务数据以及 R2 / Webhook 等系统凭据，需严格限制存储桶和下载文件的访问权限。系统设置 API 不返回已保存的密钥，空白表示保留，勾选清除后保存可删除。原有业务 JSON 导出仍不包含这些系统凭据。物料图片存储在外部图床，SQLite 备份仅含图片 URL。

业务备份版本 22 增加验收单系统核对确认状态，并包含品质图表规则、逐 Sheet 物料绑定及保存时的物料快照，并保留品质模板、不可变发布版本、验收单解析结果及 R2 Excel 文件引用及按数据 Sheet 分组的结果（兼容版本 17 的模板备份、版本 18 的单 Sheet 验收记录和版本 19 的多 Sheet 结果及版本 20 的物料绑定；版本 20 及更早备份恢复为空图表列表，版本 19 及更早备份恢复为未绑定物料）。SQLite 和 JSON 备份保存模板规则、验收单结果、预览快照和原文件位置，Excel 二进制独立保留在 R2；完整恢复需要对应 R2 对象仍可访问。停用模板、恢复及重置业务数据均不删除 R2 Excel 对象。迁移到其他 R2 账户/存储桶需要同步原文件，不能只改连接配置。原文件缺失时，下载和启用会明确报错，预览快照不能替代原始 Excel。

## 恢复

完整 SQLite 文件不能通过业务 JSON 恢复入口导入。

1. 从 R2 下载所需 `.sqlite` 文件到安全位置，使用 SQLite `PRAGMA integrity_check` 检查，预期为 `ok`。
2. 停止所有连接此数据库的 ERP 服务，妥善保留现有数据库及其 `-wal`、`-shm` 文件作为回退副本。
3. 将下载文件替换到 `DB_PATH` 指定位置；不要留下原数据库的 `-wal`、`-shm` 文件，设置正确的文件属主与权限。
4. 建议在首次启动前对恢复副本执行以下 SQL，清理旧登录会话，并暂停备份计划，待核对配置和数据后再启用：

```sql
DELETE FROM auth_sessions;
UPDATE r2_backup_settings
SET config=json_set(config, '$.enabled', json('false'));
```

5. 启动服务，使用备份时的管理员账号登录，核对仓库、库存、单据、图床和备份配置，再启用计划。恢复会回到备份时的账号、密码与系统凭据，请按需要轮换失效或已泄露的凭据。

建议定期在隔离环境验证下载、完整性检查和恢复流程。

验收单上传原文件使用同一 Excel 前缀下的 `acceptances/` 子目录，与 `templates/` 原表分开。解析预览不上传对象；只有确认保存且解析通过后，才保存原文件和验收记录。历史验收单固定引用发布版本，模板停用或发布新版本不改写历史结果。

模板规则仍只绑定一个样表 Sheet。导入可选择多个名称不同的数据 Sheet 复用此规则；这些结果统一保存在一张验收单中，按原数据 Sheet 名称分组，不改写模板。

品质自动核对的测量值、规则版本和每个 Sheet 的核对结果随验收单快照备份。版本 21 及更早备份恢复时，核对确认状态默认为未确认；原先无核对规则的验收单不增加或重算核对结果。
